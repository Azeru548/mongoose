This is the `mongoose:report` command. It reads `output/verifier_results.json` (generated by `OTTER_SIGNALS_ONLY=1 npm run verify:ci` after `scripts/build-and-deploy.sh`) and prints the Mongoose verification report.

If the file does not exist, tell the user to run the full verifier pipeline first:

```
solana-test-validator --reset --quiet &
./scripts/build-and-deploy.sh
OTTER_SIGNALS_ONLY=1 npm run verify:ci
# or: npm run report -- output/verifier_results.json
```

See README.md "CI Verifier" and "Reproduction Guide" for details. The plugin's `command.execute.before` hook handles this command and renders the report directly — no LLM reimplementation.
